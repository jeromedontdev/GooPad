Device Settings

Apple Home

Save an Apple Home switch tile first. Then open pairing below and add GooPad in the Apple Home app using More options and the setup code. Create Home automations to control your lights or other accessories. Adding or renaming switches restarts GooPad.

Keep the setup code private. HomeKit pairing keys are stored on the device; without flash encryption, someone with physical flash access can read them.

Windows Companion

Run Companion and choose Copy Secure Pairing, then paste the code below. Show setup help.

Save Settings saves this pairing for all PC macros. GooPad verifies this specific Companion certificate and never falls back to HTTP. Only copy pairing directly from your own PC.

Website Appearance

Change the editor colors independently of the device. This preference is saved in this browser.

Backup

Save or restore the configuration on the SD card. Images, sounds, Wi-Fi credentials and Apple Home pairing are not included. Backups can contain secrets.

Firmware

Check for an update or upload an application firmware image. To install from SD, use Settings on the GooPad screen.

Admin Password

Set a new password for the admin account. Use 8-64 printable characters. After saving, sign in again with the new password.

Saved Images

Delete unused images, GIFs and backgrounds from SD. Images used by the saved layout cannot be deleted. Clear their references and save first. This does not delete fonts, resources, sounds, backups or pairing.

Diagnostics

Download a bounded diagnostic report to share when requesting help. It contains numeric event codes and memory statistics, not URLs, passwords, tokens, network names or widget data. Raw serial logs and backups are not safe to share.

Connect Your Windows PC

  1. Download and extract the Companion ZIP. Run GooPadCompanion.exe as your normal Windows user, not as Administrator.
  2. Keep the app running. Choose Copy Secure Pairing, paste the code in GooPad Settings → Windows Companion, and choose Apply Secure Pairing. This includes its HTTPS address, private token and public certificate. Only copy it directly from your own PC; never paste a private key.
  3. Allow the app through Windows Firewall only on a Private network. Port 8787 must be reachable from GooPad.
  4. Choose Check HTTPS Connection, then Save Settings. In Tiles, choose Macro, pick a starter or add your own steps, then Save to Device.
  5. Focus the intended Windows app before pressing a tile. Hotkeys and typed text go to the foreground application; media keys use Windows media controls.

Both links use HTTPS. GooPad verifies the specific Companion certificate you paired. The PC does the work; it does not need a USB cable to GooPad.

Upgrading from an older app: import secure pairing and save your PC macros again to update their URLs. Old HTTP actions are blocked until migrated. Your pairing token and local permissions remain unchanged.

Help and Examples

Build a PC Macro Without JSON

Choose a starter such as Copy, Paste, Screenshot, Play/Pause, or Mute. Each step can press a hotkey, send a media key, type text, wait, open a website, run PowerShell, or launch an app already approved on the PC. Use the arrow buttons to reorder steps. A sequence can contain up to 12 steps, with at most 10 seconds of waiting in total.

Example: add Ctrl+L, Type Text with a website address, and Enter to use a focused browser. Or simply use Open Website to open a link in the default browser. Add a short Wait if an app needs time between steps.

PowerShell and Approved Apps

PowerShell is disabled by default. Enable it locally in Companion only if you trust your LAN and everyone with the pairing token. Then choose a PowerShell step and enter your command (up to 512 characters). Scripts run as your Windows user, with a 10-second timeout. Errors stop the rest of the sequence and appear in Companion and the connection/last-result check.

For fixed app launches or SSH, advanced users can add named actions in %LOCALAPPDATA%\GooPad\companion.json. Each action specifies a program and fixed arguments. Enter that name in an Approved PC app step. The device cannot change those arguments. See the source README for examples.

Keep Companion Running / Start with Windows

Start with Windows opens Companion at user sign-in. Enable Hide in the Tray on Windows Startup to start without a taskbar window. Close and Minimize each have their own tray preference. Defaults remain Close = quit and Minimize = taskbar. Hidden Companion still receives commands; use its tray menu to Open or Quit.

Manual and automatic startup support the same actions, including locally enabled PowerShell. Keyboard macros require an awake, unlocked desktop. Signing out stops Companion. Startup needs no administrator access and no Windows service is installed. The packaged app uses a stable copy under %LOCALAPPDATA%\GooPad\bin. Uncheck Start with Windows to disable autostart.

Device Menu and Appearance

Swipe downward from the top edge of GooPad to slide open the information menu. Its Settings controls display brightness, sound volume, and SD firmware installation. Brightness and volume retain the board's safe power limits. Change themes and appearance from this website, not the device menu.

Widgets and PC Stats

Choose Widgets, then a category such as Clock or PC and a type. Time and Date have their own format choices; seconds are optional for Time. The UTC offset in Settings initially matches your browser; update it after daylight-saving changes.

Each PC stats tile selects CPU/RAM combined, CPU usage, RAM percentage/used GiB, GPU usage/dedicated memory, or CPU/GPU temperature in Celsius/Fahrenheit. Pair Companion in Settings and save. CPU/RAM refresh every five seconds; GPU/sensors are cached about ten seconds. GPU usage is the busiest engine; GPU memory sums dedicated memory across adapters.

GPU counters need supported Windows drivers. NVIDIA's driver may provide GPU temperature through nvidia-smi. For CPU temperatures and other GPU sensors, run the official LibreHardwareMonitor Windows Forms app alongside Companion; its WMI provider supplies readings without enabling a remote web server. Some sensors require that sensor app to run as administrator. Keep Companion as your normal user. Missing sensors show Unavailable, never zero.

GIFs and Empty Tiles

Animated GIF visuals require SD: at most 160x160 pixels, 128 KB, 240 frames, and four GIF tiles. The device caps playback at 10 fps and pauses off-screen animations; browser previews may be faster. Open Layout Settings below the preview and enable Hide Empty Tiles to remove empty boxes without moving configured tiles. Empty spaces remain editable and accept dragged tiles in the preview. Alternatively, Compact Configured Tiles packs configured tiles together and hides unused pages. Save to apply either option to the device.

Connection or Action Not Working

Confirm both devices are on the same trusted LAN, the updated HTTPS Companion is open, and its address/token/public certificate match Settings. Guest Wi-Fi can block communication. Check the Private-network firewall rule for TCP 8787. Reserve the PC's IP in your router if it changes. Never bypass certificate checks to fix a connection.

Use Test Saved Action to run a saved macro after confirmation. Live preview reports running, HTTP success/rejection, or transport/TLS failure. HTTP 204 means a webhook succeeded. Only one PC sequence runs at a time; repeated taps while busy are rejected instead of overlapping keys. Check the app's last-result message. Windows blocks input into administrator apps, locked screens, and some games. Media-key handling depends on the media app. Try a normal Notepad window for a text/hotkey macro.

Backgrounds, Saving, and Security

Open Tiles → Layout Settings and select Custom to upload a background image; an SD card is required. Images are cropped to fill the screen. Choose a preset to temporarily use its palette instead. Save to Device applies the layout; Save Settings returns to the preview so progress and errors appear only once.

Keep passwords and pairing codes private. Never forward GooPad or Companion ports to the internet. The GooPad editor uses self-signed HTTPS; its Companion link uses verified HTTPS with the paired public certificate and has no HTTP fallback. Use only trusted private Wi-Fi. Backups and the development firmware's NVS are not encrypted. Keep Companion's certificate and private key together on your PC; replacing them requires pairing again.
