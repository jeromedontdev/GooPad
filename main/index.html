About GooPad

Your local Wi-Fi macro pad. Edit here, save to the device, then press a tile to run its action.

Download Windows Companion app (ZIP)Source on GitHubFirmware and releases

Extract the entire ZIP, then run GooPadCompanion.exe. No Python installation is required for the Windows app. Source and the Python launcher are included. Only run downloads from the GooPad repository.

Connect your Windows PC

  1. Download and extract the Companion ZIP. Run GooPadCompanion.exe as your normal Windows user, not as Administrator.
  2. Keep the app running. Use Copy PC address, then paste it in GooPad Settings → Windows companion.
  3. Use Copy private pairing token and paste it beside the address. This token is different from the GooPad admin password.
  4. Allow the app through Windows Firewall only on a Private network. Port 8787 must be reachable from GooPad.
  5. Choose Check connection, then Save appearance. In Macros, choose Windows PC macro, pick a starter or add your own steps, then Save to device.
  6. Focus the intended Windows app before pressing a tile. Hotkeys and typed text go to the foreground application; media keys use Windows media controls.

The browser talks to GooPad over HTTPS. GooPad sends authenticated commands to Companion over your LAN. The PC does the work; it does not need a USB cable to GooPad.

Help and examples

Build a PC macro without JSON

Choose a starter such as Copy, Paste, Screenshot, Play/Pause, or Mute. Each step can press a hotkey, send a media key, type text, wait, open a website, run PowerShell, or launch an app already approved on the PC. Use the arrow buttons to reorder steps. A sequence can contain up to 12 steps, with at most 10 seconds of waiting in total.

Example: add Ctrl+L, Type text with a website address, and Enter to use a focused browser. Or simply use Open website to open a link in the default browser. Add a short Wait if an app needs time between steps.

PowerShell and approved apps

PowerShell is disabled by default. Enable it locally in Companion only if you trust your LAN and everyone with the pairing token. Then choose a PowerShell step and enter your command (up to 512 characters). Scripts run as your Windows user, with a 10-second timeout. Errors stop the rest of the sequence and appear in Companion and the connection/last-result check.

For fixed app launches or SSH, advanced users can add named actions in %LOCALAPPDATA%\GooPad\companion.json. Each action specifies a program and fixed arguments. Enter that name in an Approved PC app step. The device cannot change those arguments. See the source README for examples.

Keep Companion running / start with Windows

Start with Windows opens Companion at user sign-in. Enable Hide in the tray on Windows startup to start without a taskbar window. Close and Minimize each have their own tray preference. Defaults remain Close = quit and Minimize = taskbar. Hidden Companion still receives commands; use its tray menu to Open or Quit.

Manual and automatic startup support the same actions, including locally enabled PowerShell. Keyboard macros require an awake, unlocked desktop. Signing out stops Companion. Startup needs no administrator access and no Windows service is installed. The packaged app uses a stable copy under %LOCALAPPDATA%\GooPad\bin. Uncheck Start with Windows to disable autostart.

Live widgets and PC monitoring

Choose Live widget for a clock, date, or PC CPU/RAM display. Widgets do not run actions when tapped. Clock/date sync over Wi-Fi or when you open this website. The fixed UTC offset in Settings initially matches your browser; update it after daylight-saving changes. PC usage refreshes every five seconds and requires a paired, reachable Companion.

GIFs and empty tiles

Animated GIF visuals require SD: at most 160x160 pixels, 128 KB, 240 frames, and four GIF tiles. The device caps playback at 10 fps and pauses off-screen animations; browser previews may be faster. Unconfigured tiles are blank and inactive, without a plus sign. Enable Hide unconfigured tiles to compact the grid while keeping action assignments intact.

Connection or action not working

Confirm both devices are on the same trusted LAN, Companion is open, and its current address/token match Settings. Guest Wi-Fi can block communication. Check the Private-network firewall rule for TCP 8787. Reserve the PC's IP in your router if it changes. An old Companion supports only basic actions: download the latest app for the builder.

Only one PC sequence runs at a time; repeated taps while busy are rejected instead of overlapping keys. Check the app's last-result message. Windows blocks input into administrator apps, locked screens, and some games. Media-key handling depends on the media app. Try a normal Notepad window for a text/hotkey macro.

Backgrounds, saving, and security

Select Custom in Settings to upload a background image; an SD card is required. Images are cropped to fill the screen. Choose a preset to temporarily use its palette instead. Save appearance returns to Live preview, where saving progress and errors appear only once.

Keep both passwords/tokens private. Never forward GooPad or Companion ports to the internet. The GooPad editor uses self-signed HTTPS; the Companion LAN link is HTTP, so its token is not encrypted in transit. Use only trusted private Wi-Fi. Backups and the development firmware's NVS are not encrypted.
